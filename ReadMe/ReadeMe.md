# AR Product Showcase

## Project Description

AR Product Showcase is a web-based Augmented Reality application developed using HTML, CSS, JavaScript, A-Frame, and AR.js.

Users can scan a Hiro marker using a camera to view interactive 3D objects in an augmented reality environment.

## Technologies Used

- HTML
- CSS
- JavaScript
- A-Frame
- AR.js
- glTF / GLB

## Main Features

1. Hiro Marker Detection
2. Four 3D Primitive Objects
3. 3D Robot Model
4. Rotating Box Animation
5. Moving Sphere Animation
6. Ball Colour Change Interaction
7. Custom Box Grow Interaction
8. Marker Found and Lost Status Banner

## How to Run

1. Download or clone this repository.
2. Open the project in Visual Studio Code.
3. Install the Live Server extension.
4. Open index.html using Live Server.
5. Allow camera access.
6. Show the Hiro marker to the camera.
